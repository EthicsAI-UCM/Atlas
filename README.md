## Descripción de Proyecto

Software centrado en control y monitoreo de embarcaciones tanto de ámbito industrial como de uso recreacional. 
Su objetvo se centra en gestión de riesgos de todo tipo, desde el ámbito sanitario preventivo hasta problemas de integridad física.
